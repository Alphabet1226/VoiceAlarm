## [1.1.0] - 2026-11-17

### 🌟 顶级 UI & UX 全面焕新

本次大版本更新由顶级 Android 架构师与顶级 UX 设计师视角出发，贯彻**第一性原理**与**奥卡姆剃刀原则**：在**零额外依赖、纯原生轻量化（包体积仅 218KB）**的前提下，重构了全部界面视觉交互与系统体验。

#### Added (新增功能与交互)
- **All-in-One 沉浸式设定面板 (`AlarmEditDialog`)**：
  - 彻底终结原有割裂的两段式连环弹窗体验；
  - 同屏整合：原生时间滚轮 (TimePicker)、周期快速胶囊 (仅响一次 / 工作日 / 每天 / 周末)、周一至周日 7 颗圆球独立自选；
  - 备注预设词贴纸库：提供【起床】、【晨练】、【晨会】、【吃药】、【出门】等一键填入胶囊；
  - **实时 TTS 语音试听按键**：支持在设定时即刻朗读报时效果，所见即所听。
- **智能下次响铃状态横幅 (Hero Countdown Banner)**：
  - 主页顶部动态计算并置顶展示最近一次响铃时间与剩余倒计时（例如：“明天 07:00 · 还有 8 小时 15 分钟”），极大减轻用户心智负担。
- **列表卡片快捷语音试听**：
  - 每个闹钟卡片内置独立的小喇叭试听图标，无需开启响铃即可一键试听 TTS 播报。
- **动态声波同心圆动效 (`PulseWaveView`)**：
  - 响铃全屏界面引入 3 层平滑向外扩散呼吸淡出的同心圆声波动画，伴随语音报时温和律动，营造沉浸科技美感。
- **物理音量键贪睡控制**：
  - 响铃时支持物理音量加/减按键快捷触发 5 分钟稍后提醒（Snooze），方便清晨床头盲操。
- **触觉反馈体系 (`HapticUtil`)**：
  - 开关切换、保存按键、卡片长按等交互环节全面注入细腻触感回馈。
- **全套高品质矢量图形 (VectorDrawables)**：
  - 新增闹钟时钟、扬声器声波、极简空状态艺术插画、圆角药丸等无损矢量资产。

#### Changed (体验与架构优化)
- **全面屏 Edge-to-Edge 边到边沉浸适配**：
  - 动态监听 WindowInsets 安全区避让，完美适配任意打孔屏、刘海屏与手势导航条。
- **Material 3 规范色彩与深色模式基线**：
  - 重构浅色（#F8F9FA 冷灰基调）与深色（#0D1117 OLED 黑夜）语义化 Token，告别代码生硬硬编码，深色模式自动无缝过渡。
- **卡片质感升级**：
  - 采用 20dp 优雅大圆角与半透明水波纹（RippleDrawable）；闹钟关闭时整卡平滑半透明淡化，层级主次分明。
- **响铃全屏界面护眼重构**：
  - 升级为晨起护眼极暗黑底（#0A0E17），大字号 64sp 极细走时数字，底部大触控区稍后提醒与关闭大药丸按钮。
- **代码重构与单一真相来源**：
  - 抽象出 `TTSPreviewHelper` 统一管理全应用中文报时语义生成与播放状态。

## [1.0.0] - 2026-11-17

### 初始发布
- 基于原生 `AlarmManager.setAlarmClock()` 构建最高优先级精确响铃与全屏唤醒；
- 基于 Android 文本转语音 (TTS) 自动生成自然中文时间报时与自定义备注朗读；
- 支持 5 分钟贪睡 (Snooze) 与后台呼吸循环播报；
- 本地 SharedPreferences 轻量 JSON 持久化；
- 0 第三方依赖的极简原生架构。
